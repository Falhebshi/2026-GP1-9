# Jaadah

Jaadah (جادَة) is a graduation project developed at King Saud University.

Jaadah is a web-based traffic digital twin proof of concept that aims to support traffic engineers and urban planners in analyzing traffic conditions and evaluating possible traffic interventions before applying them to the real road network.

The project combines road network and traffic data, microscopic traffic simulation, traffic engineering analysis, artificial intelligence, and a web-based dashboard.

## Main Features

- View traffic conditions to understand the wider context of the selected intersection.
- Analyze the selected intersection using microscopic traffic simulation.
- Evaluate traffic performance using traffic KPIs.
- Detect recurring and abnormal traffic conditions.
- Forecast short-term traffic conditions.
- Recommend possible traffic interventions.
- Compare baseline and post-intervention simulation results.

## Technologies

The current planned technologies include:

- Python
- SUMO and TraCI
- OpenStreetMap / OSMnx
- Pandas and GeoPandas
- scikit-learn
- Streamlit
- pydeck / deck.gl
- Git and GitHub
